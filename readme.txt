Spontane Jitsi-Sparring-Sessions für BuddyPress-Communities.

== Beschreibung ==

Mitglieder können mit einem Klick eine spontane Jitsi-Video-Session starten ("Sparring").
Die Community wird sofort per BuddyPress Activity Stream und E-Mail benachrichtigt.
Interessierte Mitglieder können direkt beitreten – kein Account nötig.

**Features:**
* Jitsi-Server konfigurierbar (Standard: meet.jit.si)
* BuddyPress Activity Stream Integration mit LIVE-Badge
* E-Mail-Benachrichtigung an Community oder BP-Gruppe
* Live-Teilnehmerzähler (15-Sekunden-Polling)
* Session beenden + Feedback-Funktion
* WP Admin Einstellungsseite

== Installation ==

1. Plugin-Ordner nach `/wp-content/plugins/bp-jitsi-sparring/` hochladen
2. Plugin in WordPress aktivieren
3. Einstellungen unter Einstellungen → BP Jitsi Sparring anpassen

== Voraussetzungen ==

* WordPress 5.8+
* BuddyPress (aktiv)
